# UI Foundry Spinner Component Generator

Standalone visual spinner generator built with Next.js.

This app is a focused loading-indicator studio for circular, dot-based, bar-based, and more expressive spinner treatments that can be edited visually and exported as code.

## Product summary

This generator is designed for:

- designers building loading states, waiting screens, and async feedback UI
- developers who want configurable loading indicators instead of rebuilding them manually
- freelancers and agencies preparing branded loading treatments for client products
- buyers who want a standalone spinner tool with a visual editor and export support

## What the product includes

- section-based editing controls
- live preview panel
- code view with copy support
- file export support
- searchable preset library
- generated premium preset catalog with filters, paging, and surprise-me apply
- undo and redo controls
- self-contained standalone app structure

## Editing coverage

The editor currently includes these control areas:

- Presets
- Basics
- Metadata
- Sizing
- Colors
- Surface
- Track
- Status
- Depth
- Effects
- Distortion
- Particles
- Motion
- Labels
- Accessibility

These sections cover spinner structure, sizing, rail treatment, depth, distortion, particle density, label behavior, status copy, and accessibility metadata.

## Export workflow

The spinner preview and code output stay tied to the same current state so the generated result follows the visual editor closely.

## Why this product is useful

This is more than a single loading spinner snippet. It gives the buyer a configurable loading-indicator studio with multiple visual directions.
