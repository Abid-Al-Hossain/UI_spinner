# Changelog

## 0.1.3 - 2026-04-03

- split spinner editing into denser native families with dedicated `Track`, `Distortion`, and `Particles` sections
- narrowed `Surface` to stroke contour treatment and narrowed `Effects` to light/shadow responsibility only
- preserved clean `typecheck`, `lint -- --quiet`, and production `build` verification after the spinner depth expansion

## 0.1.2 - 2026-03-31

- expanded the preset system from starter packs into larger generated button-style preset catalogs
- aligned the preset browser and preview reset flow more closely with the button-component product model
- preserved clean lint, typecheck, and production build verification after the canon sync

## 0.1.1 - 2026-03-31

- added a searchable preset catalog with full-state preset apply flow
- aligned the spinner studio more closely with the button-style UI Foundry editing model
- preserved clean lint, typecheck, and production build verification after the preset rollout

## 0.1.0 - 2026-03-30

- stabilized the standalone spinner app so build, lint, and typecheck pass
- synced shared layout and control primitives to the UI Foundry standard
- improved label rendering and export behavior for richer spinner variants
